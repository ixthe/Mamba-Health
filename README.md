# Mamba Health Tracker 🐍💚

Uma Single Page Application (SPA) desenvolvida com Vue.js 3 para auxiliar usuários no acompanhamento de saúde e hábitos alimentares, com foco em:

* ⏱️ Controle de Jejum Intermitente
* 🍎 Monitoramento Calórico
* 📊 Acompanhamento de progresso
* 💾 Persistência de dados localmente

## 🚀 Tecnologias Utilizadas

* Vue.js 3
* Vue Router
* JavaScript
* HTML5
* CSS3
* LocalStorage

## 📌 Funcionalidades

* Cadastro e visualização de refeições
* Controle de calorias consumidas
* Registro de períodos de jejum
* Navegação entre páginas utilizando Vue Router
* Componentes reutilizáveis
* Interface simples e responsiva
* Armazenamento local dos dados do usuário
